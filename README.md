# Wheel of Times API

The Wheel of Time is an epic fantasy series by Robert Jordan, later completed by Brandon Sanderson, spanning fourteen books and a prequel. Known for its rich world-building, deep character arcs, and extensive foreshadowing, it’s a New York Times bestseller translated into many languages.

This API provides access to detailed information about the characters, locations, and events within the Wheel of Time universe.

## API Endpoints

### Available

- `GET /api/characters/v1/`: Retrieve a list of all characters.

### Under Development

- `GET /api/books/v1/`
- `GET /api/nations/v1/`
- `GET /api/groups/v1/`
